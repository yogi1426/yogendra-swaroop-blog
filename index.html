Breaking things so they can be built securely.

I'm Yogendra. I started out breaking into systems for a living — red team, exploits, the whole "try harder" grind — before switching sides to defend a fintech platform used by millions. These days I spend more time reading pull requests than writing exploits, but the instinct is the same: find the flaw before someone with worse intentions does. This is where I write down what that actually looks like — the wins, the near-misses, and the things nobody puts in a case study.
